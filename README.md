# OBSTACLES
### A game developed by Alim B.A.
#### DESCRIPTION
  A simple 2D Pixel game where you maneuver a small avatar through series of levels with obstacles that gradually get more complex. Try your best not to get hit :)
#### HOW TO RUN GAME
  Locate the .exe file above and right-click. Agree to the terms and conditions, then click 'next' and 'install'.
